# SoftwareFJ - Sistema de Gestión de Reservas

Proyecto de Programación Orientada a Objetos - UNAD
Estudiante: Luis David Rodriguez

## Descripción
Sistema para gestionar clientes, servicios y reservas de la empresa FJ.
Permite agregar clientes, agregar servicios, crear reservas, cancelar reservas y generar registro en logs.txt

## Clases
- Cliente: id, nombre, correo, telefono
- Servicio: id, nombre, descripcion, precio, capacidad
- Reserva: id, cliente, servicio, fecha, estado

## Cómo ejecutarlo
1. Abrir el archivo SoftwareFJ.py en VS Code
2. Dar clic en Run
3. Verificar que se genere el archivo logs.txt

## Archivos
- SoftwareFJ.py -> Código fuente
- logs.txt -> Registro de operaciones
